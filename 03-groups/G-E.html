节点目录 (9 个)

节点 ID名称来源阶段简介
int-ghaGitHub Actions 集成桥接进阶composite action（action.yml）封装完整审查流程，workflow 中一行引用即可接入
int-cicd其他 CI 集成桥接高级examples/ 目录提供 6 套非 GitHub CI 集成模板：gitlab_ci、gerrit_ci、gitflic_ci、bitbucket_pipelines、codeup_ci
int-claudeClaude Code 插件桥接高级Alibaba Open Code Review 为 Claude Code 提供的官方集成插件，仓库路径为 plugins/open-code-review/claude-code/，核心清单文件为 .claude-plugin/plugin.json，其中 commands 字段指向 ./commands 目录，即插件以斜杠命令（slash command）形式暴露能力
int-codexCodex 插件桥接高级Alibaba Open Code Review 为 OpenAI Codex（CLI/Agent 形态）提供的官方集成，插件清单 .codex-plugin/plugin.json 声明 skills: ./skills/ 目录，即通过 Skill 机制暴露审查能力
int-cursorCursor 插件桥接高级Alibaba Open Code Review 为 Cursor（AI 编辑器）提供的集成插件，清单文件 .cursor-plugin/plugin.json，其 skills 字段指向 ../skills/ 目录，即复用仓库通用 skills 目录中的同一份 Skill 定义
int-opencodeOpenCode 原生插件桥接高级Alibaba Open Code Review 为 OpenCode（本工具）提供的原生插件，文件为 plugins/open-code-review/opencode/open-code-review.ts，基于 @opencode-ai/plugin 官方插件 SDK 开发
int-qcaQCA Forward 委托桥接高级「QCA Forward」是一种委托（delegate）模式，配置位于 qca/ 目录，核心文件为 system-prompt.md 与 template.example.json
int-skill通用 Agent Skill桥接高级Open Code Review 以 Skill 形态向任意支持 skill 机制的 Agent 暴露能力，核心文件为 skills/open-code-review/SKILL.md 与 skills/open-code-review-delegate/SKILL.md
int-vscodeVSCode 扩展桥接高级Open Code Review 提供 VSCode 官方扩展，代码位于仓库 extensions/vscode/ 目录，面向编辑器内审查场景
