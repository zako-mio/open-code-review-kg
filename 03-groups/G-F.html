节点目录 (6 个)

节点 ID名称来源阶段简介
q-benchAACR-Bench 基准桥接进阶AACR-Bench 是 Open Code Review 项目构建的自动化 AI 代码审查基准（Automated AI Code Review benchmark），用于评测与对比 AI 审查能力
q-telemetryOpenTelemetry 遥测桥接高级OCR 内置 OpenTelemetry 双管道（trace + metric），所有审查事件与指标均通过统一遥测框架埋点
q-security安全设计桥接高级FileReader 路径穿越防护：所有文件读取经 pathutil.WithinBase + EvalSymlinks 双重校验，符号链接与 ../ 均无法逃逸仓库根目录
q-retry重试与错误分类桥接高级底层 SDK 内建 max-retries=5 重试策略，配合 retryCodesMiddleware 自动注入 x-should-retry 头驱动服务端重试语义
q-release构建与发布体系桥接高级npm 包 @alibaba-group/open-code-review 作为分发入口，bin 指向 bin/ocr.js，postinstall 钩子自动下载对应平台原生二进制
q-tokenToken 计费与成本控制桥接进阶基于 tiktoken-go 精确计费：o1/o3/o4 系列用 o200k_base，其余模型用 cl100k_base，分词口径与 OpenAI 一致
