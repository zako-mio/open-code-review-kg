组简介

本组 9 个节点，属于 CLI 域，类型为 工具，覆盖阶段 基础 / 进阶 / 高级。

组节点：ocr 命令总览与安装、ocr review、ocr scan、ocr delegate、ocr config、ocr session、ocr viewer、ocr rules、ocr llm

节点目录 (9 个)

节点 ID名称来源阶段简介
cli-overviewocr 命令总览与安装桥接基础ocr 是阿里巴巴开源的 AI 代码审查 CLI 工具（项目 alibaba/open-code-review），以 Go 编写，命令名为 ocr，面向开发者提供本地化、可自定义的代码审查能力
cli-reviewocr review桥接基础ocr review 是工具的主命令，基于 git 变更执行 AI 代码审查，是日常使用频率最高的入口
cli-scanocr scan桥接基础ocr scan 是全文件扫描模式，不依赖 git 历史与 diff，直接对磁盘上的源码文件逐个审查，覆盖 review 模式无法触及的历史遗留问题
cli-delegateocr delegate桥接进阶ocr delegate 是委托模式：工具自身不调用 LLM，只负责分析准备，把审查工作委托给宿主编码 Agent（如 Cursor/Claude Code 等）用自己的模型完成
cli-configocr config桥接基础ocr config 是配置管理命令，统一管理模型提供商、模型名、token 上限、自定义提供商、MCP 服务器、LLM 行为、语言与遥测等配置项
cli-sessionocr session桥接进阶ocr session 是会话管理命令，管理审查任务的持久化会话，会话数据定位在 ~/.opencodereview/sessions/ 目录
cli-viewerocr viewer桥接进阶ocr viewer 是 WebUI 会话查看器，以本地网页形式可视化回放审查会话，默认监听 localhost:5483
cli-rulesocr rules桥接高级ocr rules 是规则调试命令，核心子命令为 check：ocr rules check <file-path> 显示指定文件命中的规则层与匹配模式
cli-llmocr llm桥接高级ocr llm 是 LLM 工具命令，用于模型层的连通性验证与能力查询，是排查模型配置问题的第一站
