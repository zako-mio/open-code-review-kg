组简介

本组 10 个节点，属于 核心机制 域，类型为 架构/机制，覆盖阶段 基础 / 进阶 / 高级。

组节点：Git Diff 获取与解析、文件选择与过滤、文件分束、行号定位回退链、跨文件与 LLM 重定位、上下文三区压缩、会话 JSONL 持久化、断点续审与指纹复用、Run Manifest 覆盖度契约、全文件扫描引擎

节点目录 (10 个)

节点 ID名称来源阶段简介
eng-diffGit Diff 获取与解析桥接基础diff 获取支持三种 Provider，按用户场景选择：range（区间对比）、commit（单提交审查）、workspace（工作区未提交改动）
eng-filter文件选择与过滤桥接进阶文件过滤由 whyExcluded 过滤链完成，按固定顺序执行：binary（二进制）→ 用户 exclude（显式排除）→ 用户 include（显式包含覆盖）→ 扩展名白名单（unsupported_ext）→ 默认路径黑名单（default_path）
eng-bundling文件分束桥接进阶文件分束是 open-code-review 将一次评审拆解为多个可并行子任务的核心调度机制，决定 diff/文件集合如何被组织成独立任务单元
eng-locator行号定位回退链桥接进阶行号定位回退链解决『审查评论最终必须落在哪个文件的哪几行』的定位问题，是评论回填 Collector 前的最后一步精确对齐
eng-relocate跨文件与 LLM 重定位桥接高级重定位机制负责把在原文件无法定位的评论迁移到正确的目标文件与行号，分确定性层（RelocateAcrossFiles）与推理层（ReLocateComment）
eng-compression上下文三区压缩桥接高级上下文压缩把会话消息划分为三个区：frozen（messages[0:2] 系统/前置固定区）+ compress 区（可压缩区）+ active 区（最近活动区）
eng-session会话 JSONL 持久化桥接高级会话持久化把每次代码审查的完整执行轨迹以 JSONL 落盘，默认目录 ~/.opencodereview/sessions/
eng-resume断点续审与指纹复用桥接高级断点续审通过任务指纹复用跳过已完成审查，从断点继续执行未决项
eng-manifestRun Manifest 覆盖度契约桥接高级Run Manifest 是审查运行的覆盖度契约，声明本次审查覆盖了哪些项、每项什么状态、哪些失败，schema 标识为 'ocr.run-manifest/v1'
eng-scan全文件扫描引擎桥接高级全文件扫描引擎实现无 diff 审查：不依赖 git diff，对仓库全量文件内容做审查

学习路径提示

本组内存在 7 条前置依赖边（prerequisite），推荐先掌握前置知识点，再进入依赖它的节点。

推荐阅读顺序（拓扑序）
文件分束 → 上下文三区压缩 → Git Diff 获取与解析 → 全文件扫描引擎 → 会话 JSONL 持久化 → 文件选择与过滤 → Run Manifest 覆盖度契约 → 行号定位回退链 → 断点续审与指纹复用 → 跨文件与 LLM 重定位
  • Git Diff 获取与解析 → 文件选择与过滤过滤基于解析后的 diff
  • Git Diff 获取与解析 → 行号定位回退链行号映射基于 hunk
  • 文件选择与过滤 → 行号定位回退链定位发生在保留文件上
  • 行号定位回退链 → 跨文件与 LLM 重定位定位失败才触发重定位
  • 会话 JSONL 持久化 → 断点续审与指纹复用续审依赖会话持久化
  • 会话 JSONL 持久化 → Run Manifest 覆盖度契约manifest 随会话落盘
  • Run Manifest 覆盖度契约 → 断点续审与指纹复用复用必须过父 manifest

入组前置依赖（组外节点 → 本组成员）

  • 规则引导分派 → 文件分束分派再做文件分束
  • 受限工具集审查 → 上下文三区压缩工具循环需上下文压缩

出组依赖（本组成员 → 组外节点）

  • 会话 JSONL 持久化 → ocr sessionCLI 管理 JSONL 会话
