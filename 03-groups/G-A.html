节点目录 (6 个)

节点 ID名称来源阶段简介
arch-hybrid确定性工程 × Agent 混合架构桥接基础Open Code Review 的核心设计理念：将代码审查任务拆解为『确定性工程』与『Agent』两个互补部分，而非让 LLM 全权接管所有环节
arch-pipeline审查流水线桥接基础整个审查过程被组织为 8 步时序流水线，从 CLI 入口到结果输出一气呵成，每步职责单一、可独立测试
arch-dispatch规则引导分派桥接进阶分派阶段完全由确定性代码驱动：文件选择、过滤、分束均由规则与代码完成，不依赖 LLM 决策
arch-grounded-tools受限工具集审查桥接进阶审查 Agent 只被授予 6 个受限工具：file_read（读文件）、file_find（找文件）、code_search（代码搜索）、file_read_diff（读被过滤文件的 diff）、code_comment（发表评论）、task_done（结束任务）
arch-reflection独立反思桥接高级REVIEW_FILTER_TASK 是独立于审查主循环的反思组件：主审查产出评论后，由该组件对每条评论做有效性把关，而非模型自审
arch-parallel文件级并行与上下文隔离桥接高级每个文件拥有独立的子任务上下文：各自独立的 Plan、ReAct 循环、评论集合与 token 预算，互不共享也互不污染
