节点目录 (6 个)

节点 ID名称来源阶段简介
use-pr-review场景：审查 PR/分支变更桥接基础日常审查入口：对当前工作区、分支 diff 或指定 commit 进行 AI 代码审查，是使用频率最高的场景
use-scan-codebase场景：审计陌生代码库桥接基础面向无 git 历史或无有意义 diff 的仓库：接手遗留代码、安全审计、整体摸底时用扫描模式而非 diff 模式
use-no-key场景：免 Key 委托审查桥接进阶面向没有 LLM API Key 或希望复用宿主 Agent（如 QCA、Claude Code）模型能力的场景
use-ci场景：接入 CI 流水线桥接进阶让 AI 审查自动跑在每次 MR/PR 上，无需人工触发，是规模化落地的标准形态
use-configure场景：配置模型与规则桥接进阶首次上手必做步骤：配置模型提供方与审查规则，决定审查的语言、范围与标准
use-extend场景：扩展审查能力桥接高级内置规则不够用时提供四条扩展路径：MCP 接入、自定义规则文件、--rule ad-hoc 规则、委托模式
